# Siralim Ultimate – Deutsche Community-Übersetzung

Community-Projekt für eine spielmechanisch präzise deutsche Übersetzung von **Siralim Ultimate**.

## Ziel

Die offizielle deutsche Lokalisierung enthält insbesondere bei Traits, Perks, Zaubern und Kampfbegriffen missverständliche Formulierungen. Dieses Projekt erstellt eine korrigierte deutsche Übersetzung, bei der die **mechanische Bedeutung des englischen Originals** Vorrang vor einer möglichst wörtlichen Übersetzung hat.

## Priorität

1. Traits
2. Perks / Spezialisierungen
3. Spell Gems / Zauber
4. Buffs, Debuffs, Minions und Kampfbegriffe
5. weitere Gameplay-Texte

## Installation

Siralim Ultimate unterstützt Localization Overrides. Die fertigen CSV-Dateien werden im Spielordner unter `localization_override` abgelegt. Die Dateien müssen das Format der Originaldateien aus `localization` beibehalten.

Die genaue Installationsanleitung und fertige Download-Struktur werden ergänzt, sobald die Originaldateien der aktuell verwendeten Spielversion importiert und geprüft wurden.

## Übersetzungsgrundsätze

- Englisches Original ist die Referenz für die Spielmechanik.
- Trigger wie `before`, `after`, `when`, `manually casts` und `additional` werden eindeutig unterschieden.
- `Maximum Health`, `Current Health` und `Missing Health` werden nicht vermischt.
- Wiederkehrende Spielbegriffe werden konsistent übersetzt.
- IDs, Platzhalter, Formatierung und CSV-Struktur bleiben unverändert.

## Status

Projekt eingerichtet. Als Nächstes werden die englischen Original-Lokalisierungsdateien der aktuellen Siralim-Ultimate-Version importiert.
