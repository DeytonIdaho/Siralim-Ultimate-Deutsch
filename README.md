# Siralim Ultimate – Deutsche Übersetzung

Verbesserte deutsche Übersetzungsdateien für **Siralim Ultimate**.

## Installation

1. Lade dieses Repository über **Code → Download ZIP** herunter.
2. Entpacke die ZIP-Datei.
3. Öffne den Installationsordner von Siralim Ultimate.
   - Steam: Rechtsklick auf **Siralim Ultimate** → **Verwalten** → **Lokale Dateien durchsuchen**.
4. Suche dort den Ordner, in dem Siralim Ultimate seine Sprach-/Übersetzungsdateien (`*.csv`) verwendet.
5. Sichere die vorhandenen Originaldateien, falls du später zur offiziellen Übersetzung zurückkehren möchtest.
6. Kopiere die CSV-Dateien aus diesem Repository in den entsprechenden Übersetzungsordner und bestätige das Überschreiben der vorhandenen Dateien.
7. Starte Siralim Ultimate und wähle **Deutsch** als Sprache.

## Aktualisierung

Bei einer neuen Version dieses Übersetzungsprojekts einfach die aktuellen CSV-Dateien erneut herunterladen und die bisherigen Dateien ersetzen.

## Hinweis

Dieses Projekt ist eine inoffizielle deutsche Übersetzungsüberarbeitung für Siralim Ultimate. Nach Spielupdates können die Original-Sprachdateien von Steam erneut überschrieben werden; in diesem Fall die Dateien dieses Projekts erneut installieren.
